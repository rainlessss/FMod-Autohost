# FMod Autohost

FMod Autohost is a streamlined, dedicated hosting fork of Reboot Launcher. It strips out unnecessary client side overhead to provide a lightweight, set and forget server hosting.

---

## Features

- **Lightweight:** Removed unnecessary client assets and background processes to prioritize server performance and low resource usage.
- **Auto-Restart:** Automatically reboots the game server process if it crashes or closes.
- **Multi-Language Support:** Includes pre-packaged translations for global server hosts.

---

## Installation

Download the latest installer (`FModAutohost-Setup.exe`) from the [Releases](../../releases) section.

---

## Security & False Positives

FMod Autohost is distributed as closed-source compiled software. Because FMod autohost injects a redirect dll to the fortnite process, some antivirus software might flag it as malicious. FMod autohost is fully safe though.

- **Integrity:** We attach a public VirusTotal scan report to every release tag.
- **Verification:** You can upload the downloaded installer directly to [VirusTotal](https://www.virustotal.com/) to verify the hash and scan results before running it.

If your antivirus blocks the executable during startup or server monitoring, add an exclusion for the install folder.
